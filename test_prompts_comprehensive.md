## 🎯 KEY INSIGHTS

### **🔍 Response Structure:**
1. **Always starts with context/introduction**
2. **Main content in specialized format**
3. **Often includes examples**
4. **Ends with explanation/conclusion**

### **📝 Format Hierarchy:**
1. **Math** (highest priority - specific LaTeX patterns)
2. **Code** (``` with language)
3. **JSON** (```json specifically)
4. **Tables** (| with ---)
5. **Reasoning** (numbered with **)
6. **Diagrams** (numbered with decisions)
7. **Text** (default markdown)

### **🚀 Detection Strategy:**
- **Check for specific patterns in order of priority**
- **Look for the MAIN content section, not just intro text**
- **Handle mixed content by detecting the primary format**

This comprehensive testing reveals that AI responses follow predictable patterns that can be reliably detected with simple string matching!
